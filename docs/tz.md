Пилотное задание AI Engineer (Mirrolla)
Срок выполнения: 5 рабочих дней

Цель: создание рабочего MVP AI-ассистента для менеджеров маркетплейсов Mirrolla.

Бизнес-задача
Компания Mirrolla продаёт продукцию через Wildberries и Ozon.

Менеджер ежедневно анализирует:

продажи;

остатки;

отзывы;

цены конкурентов;

SEO карточек;

динамику спроса.

На эту работу уходит несколько часов в день.

Необходимо создать AI-помощника, который сможет отвечать на вопросы менеджера и помогать принимать решения.

Исходные данные
Кандидату предоставляются:

Выгрузка продаж WB за 3 месяца.

Выгрузка продаж Ozon за 3 месяца.

Остатки по складу.

Каталог товаров.

Отзывы покупателей.

Тестовый API (имитация 1С).

Задача №1
Создать AI-ассистента.

Ассистент должен отвечать на вопросы:

Почему снизились продажи товара?

Какие товары заканчиваются?

Что нужно заказать в производство?

Какие товары растут быстрее рынка?

Какие отзывы требуют реакции?

Какие товары требуют изменения цены?

Задача №2
Создать аналитический модуль.

Ассистент должен автоматически сформировать отчёт:

Топ-10 растущих товаров.

Топ-10 падающих товаров.

Товары с критическими остатками.

Товары с негативными отзывами.

Рекомендации менеджеру.

Задача №3
Интеграция с 1С

Необходимо использовать предоставленный тестовый API.

Ассистент должен:

получать остатки;

получать продажи;

получать карточки товаров.

Реальная 1С не требуется.

Задача №4
Архитектура

Подготовить документ не более 5 страниц:

Как будет выглядеть AI-платформа Mirrolla через 12 месяцев.

Какие технологии будут использоваться.

Какие риски существуют.

Какие функции внедрять первыми.

Оценка необходимого оборудования.

Что необходимо предоставить
Исходный код.

Docker Compose.

README с инструкцией запуска.

Демонстрацию работы.

Архитектурный документ.
