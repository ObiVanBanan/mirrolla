# Установка контекста агента

Этот каталог является overlay для корня репозитория `mirrolla`.

1. Скопируйте содержимое каталога в корень проекта, сохраняя пути.
2. Запустите Claude Code из корня репозитория.
3. Выполните `/context` и проверьте, что загружен `CLAUDE.md`.
4. Для конкретных процедур используйте:
   - `/architecture-review` — проверить изменение или план против архитектуры;
   - `/implement-slice` — выполнить одно узкое изменение;
   - `/verify-change` — проверить уже сделанное изменение.
   - `/implement-file-workspace` — выполнить одну фазу upload/data workspace плана.
5. Не импортируйте все файлы из `docs/agent/` в `CLAUDE.md`: они должны читаться по необходимости, иначе постоянный контекст станет слишком большим.

Пакет намеренно не меняет production-код проекта. Он задаёт агенту контекст, границы и процедуры работы.

Для разработки загрузки файлов сначала прочитайте `docs/agent/FILE_WORKSPACE.md`, затем выполняйте по одной фазе из `docs/agent/FILE_WORKSPACE_PLAN.md`.
